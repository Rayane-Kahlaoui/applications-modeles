# Steel inspection

Use Python 3.13. From the repository root on Windows, create and activate the
project environment:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

You can also run `.\.venv\Scripts\python.exe` directly without activation.
The initial setup uses the standard library. Add dependencies here when the
project starts using them.

Project deliverables belong under `projet/`. The course checkout is a reference
for individual code snippets. This repository has its own environment and code.
